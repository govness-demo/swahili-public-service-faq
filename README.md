# Swahili public-service FAQ skill

Answers common questions about national services in Swahili and English, citing the official page.

## Overview

A skill with 400 curated question–answer pairs and the rules for citing the official source page, so an assistant answers in the citizen's language without inventing procedures.

## Interfaces

Protocol: `other`. Languages: sw, en.
